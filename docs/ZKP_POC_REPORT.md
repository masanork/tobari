# ZKPを用いたプライバシー保護型トラベルルール対応：PoC評価報告書
**Status:** Draft / Proof of Concept
**Date:** 2026-01-20

## 1. はじめに
本報告書は、Tobariプロジェクトにおけるゼロ知識証明（ZKP）およびBBS+署名を用いたFATFトラベルルール対応の実装状況と、その実務的な有効性について評価したものである。

現在のトラベルルール遵守においては、個人情報の過剰な共有（Over-sharing）と、自己管理型ウォレット（Unhosted Wallet）の所有証明におけるUXの低下が大きな課題となっている。本PoCでは、これらの課題を解決するための技術的アプローチを検証した。

## 2. 実証した主要機能

### 2.1 SCAC (Self-hosted Crypto Account Credential)
アンホステッド・ウォレットの所有権を、個人情報を直接開示することなく証明する手法。
- **技術内容:** ユーザーのDID（分散型ID）と暗号資産アドレス、およびハードウェアによる秘密鍵の所有証明を組み合わせたデジタル資格情報。
- **実務的価値:** 日本やスイス等の規制で求められる「自己管理型ウォレットの所有確認」において、UXを損なわず（1タップで完了）、かつプライバシーを保護した証明が可能。

### 2.2 BBS+署名による選択的開示 (Selective Disclosure)
一つのクレデンシャルから、必要な属性のみを抽出して提示する機能。
- **技術内容:** BBS+署名スキームを用い、生データ（住所・生年月日等）を隠したまま、「KYC済みであること」「制裁リストに該当しないこと」等の事実のみを数学的に証明。
- **実務的価値:** 相手方VASPのリスクレベルに応じたデータ最小化（Data Minimization）を実現。GDPR等のプライバシー規制とトラベルルールの相反を解消する。

### 2.3 デバイス・バインディング (Holder Binding)
クレデンシャルが正当な所有者の手元にあることを保証する仕組み。
- **技術内容:** Secure Enclave (macOS/iOS) や Passkey (WebAuthn PRF) を用いた鍵管理。
- **実務的価値:** 盗まれた個人情報による「なりすまし送金」を防止。金融機関が求める高いアシュアランス・レベルを提供。

## 3. 実務的評価

| 評価項目 | 現状の実装状況 | 実務への適用性 | 課題と展望 |
| :--- | :--- | :--- | :--- |
| **規制遵守性** | FATF Tierベースのマッピングを実装済 | 中：現行法では生データの送付が原則 | 規制当局への「同等性」の立証が必要 |
| **ユーザー体験 (UX)** | 数秒以内の証明生成 (Rust/Swift) | 高：従来の署名方式より簡便 | モバイルアプリへの統合が必要 |
| **データ最小化** | 必要最小限の開示制御が可能 | 高：GDPR遵守に大きく寄与 | 受取側VASPの受容ポリシーが必要 |
| **セキュリティ** | ハードウェア隔離環境での署名を実現 | 高：フィッシング耐性が非常に高い | 鍵紛失時のリカバリモデルの確立 |

## 4. 到達点と今後のロードマップ

### 現時点での到達点
- **BBS+署名基盤:** `packages/crypto` および `packages/civ` において、Rustによる高速な署名・証明生成エンジンを実装完了。
- **検証済みプロトコル:** mDoc (ISO 18013-5) と ZKP の統合に成功し、ハードウェア署名付きのVerifiable Presentationを生成可能。
- **MCPサーバ連携:** LLM (AI) が複雑なコンプライアンス要件を判断し、適切なZKPツールを呼び出すワークフローを確立。

### 今後の課題（提案フェーズ）
1. **ハイブリッド運用モデル:** 既存のIVMS101メッセージにZKP証明を添付する「移行期プロトコル」の策定。
2. **法的同等性の獲得:** 「住所の生データ」ではなく「住所確認済みであることのZKP証明」が法的義務を果たしていると認められるためのロビー活動・実証実験。
3. **PQCへの適応:** 署名スキームの耐量子化（ML-DSA等）とZKPの共存検証。

## 5. 結論
本PoCにより、ZKPを用いたトラベルルール対応は**「技術的には既に実用レベル」**にあることが確認された。特に、自己管理型ウォレットの所有証明においては、現行の不便な手法を代替する強力なソリューションとなる。

今後は、実務者や規制当局がこの「プライバシー保護型コンプライアンス」のメリットを享受できるよう、標準化団体（GITAや各国のVASP協会）への提案と、実環境での限定的なパイロット運用を目指すべきである。
